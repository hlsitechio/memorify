# Memorify Copilot / MCP Command Inventory

Last audited: 2026-08-09

Legend:
- [x] Ready: registered and implemented now.
- [~] Client-ready: browser command, no server handler needed.
- [ ] Declared, not wired: appears in the Copilot tool list but still needs a server handler.
- [ ] Not built yet: should exist for full dashboard control, but is not registered yet.
- [!] Security-gated: should require explicit user confirmation or should never reveal secret values.

Current count:
- Copilot commands declared in `src/copilot/actions`: 163
- Server commands ready in `backend/routes/copilot.ts`: 148
- Declared server commands still missing handlers: 0
- Client-only commands ready: 15
- Target expansion below is now registered; remaining work is hardening/media pipelines/UI migration.

Security baseline:
- Copilot actions must always run with Clerk user auth and workspace/org scoping.
- Vault secret values should not be revealed through Copilot chat.
- API key and agent token creation must be explicit, auditable, and return plaintext only once.
- MCP configuration is human-dashboard only; external agent tokens should call enabled MCP tools, not rewrite MCP config.
- Destructive commands must be marked destructive and confirmed in the app flow.
- OpenRouter Copilot should keep ZDR enabled by default.
